# Tempo Cash earnings visualization

An interactive concept showing interest earnings growing toward the next milestone. Drag the slider from $0 to $25 to see the 1,000-point field rescale across the $1, $2, $3, $5, $10, $15, and $25 milestones.

The page uses vector dots, Tempo Cash colors, and Inter Display. Open `index.html` locally or view the GitHub Pages site.
